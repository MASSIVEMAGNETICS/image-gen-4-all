## 3. The HART-Morphosis Architecture

### 3.1 Core Components

#### **3.1.1 Hybrid Autoregressive Transformer (HART)**  
A modified transformer that operates on a 2D grid of latent feature cells (not tokens).  

- **Input**: Prompt embedding → projected into a 2D latent seed grid (e.g., 16×16).  
- **Self-Attention Heads**:  
  - *Morpho-Attention*: Measures local morphogen concentration gradients.  
  - *Cosmo-Attention*: Computes gravitational attraction between feature clusters (weighted by semantic density).  
- **Output**: Next-state update for each cell, computed autoregressively per iteration.

> *Unlike standard transformers, HART does not attend to global context — only to local neighborhoods (radius ≤ 3), enabling parallelization and edge deployment.*

#### **3.1.2 Morphogenesis Engine (Biological Layer)**  
Each cell holds a state vector:  
```python
state = [morphogen_A, morphogen_B, activation, velocity_x, velocity_y]
```

**Update Rules (simplified)**:  
```python
Δmorphogen_A = diffusion_rate * (avg_neighbors_A - morphogen_A) + reaction_rate * morphogen_A * morphogen_B
Δactivation = sigmoid(morphogen_A - threshold) * (1 - activation) + noise
if activation > 0.9 and neighbor_count > 2 → spawn_new_feature("eye", "branch", "filament")
```

- **L-system grammar** embedded:  
  `F → F[+F]F[-F]F` → generates branching structures (trees, veins, lightning).  
- **Turing pattern emergence**: Spots, stripes, or labyrinthine textures arise spontaneously from noise.

#### **3.1.3 Cosmological Structure Module**  
- Each feature cluster (e.g., “eye,” “mountain”) is assigned a **mass** proportional to its semantic salience.  
- **Gravitational force** between clusters:  
  ```
  F_ij = G * (mass_i * mass_j) / ||x_i - x_j||²
  ```
- Clusters attract or repel based on semantic compatibility (e.g., “sky” attracts “clouds”; “face” repels “ocean”).  
- Simulated over 5–10 iterations to form global composition (e.g., face centered in landscape).

> *This is not clustering — it is *dynamic structuring*. The image does not get “composed”; it *coalesces*.*

#### **3.1.4 Fractal Encoding & Infinite Resolution Renderer**  
- **Storage**: Only the initial seed state (16×16×16 floats = ~4KB) + rule set (≤1KB) are saved.  
- **Rendering**: At any zoom level `z`, recursively apply morpho-cosmo rules for `z * 10` iterations.  
- **Output**: Pixel values computed on-demand via interpolation of final state grid.  
- **No upscaling** — only *deepening* of structure.

> ✅ **Infinite resolution** achieved: Zoom into a pixel — you see finer morphogen gradients, new branches, sub-features.  
> ✅ **Memory constant**: 5KB regardless of output size.  
> ✅ **No artifacts**: No pixelation, no blurring — only increasing detail.

"""
Hybrid Autoregressive Transformer (HART) Core Module
"""
import torch
import torch.nn as nn
import numpy as np
from typing import Tuple, Dict, Any, Optional

class MorphoAttention(nn.Module):
    """Morphogen gradient attention - measures local chemical concentration"""
    def __init__(self, d_model: int, num_heads: int = 4):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.qkv_proj = nn.Linear(d_model, d_model * 3)
        self.out_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, channels]
        """
        B, H, W, C = x.shape
        qkv = self.qkv_proj(x).reshape(B, H, W, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(3, 0, 4, 1, 2, 5)  # [3, B, heads, H, W, head_dim]
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # Compute attention based on morphogen gradients
        attention_weights = torch.softmax(torch.matmul(q, k.transpose(-2, -1)) / np.sqrt(self.head_dim), dim=-1)
        output = torch.matmul(attention_weights, v)
        output = output.permute(0, 2, 3, 1, 4).reshape(B, H, W, C)
        return self.out_proj(output)

class CosmoAttention(nn.Module):
    """Gravitational attention - computes attraction between feature clusters"""
    def __init__(self, d_model: int, num_heads: int = 4):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        self.qkv_proj = nn.Linear(d_model, d_model * 3)
        self.out_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, channels]
        """
        B, H, W, C = x.shape
        # Flatten spatial dimensions for distance calculation
        flat_x = x.reshape(B, H * W, C)
        qkv = self.qkv_proj(flat_x).reshape(B, H * W, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(2, 0, 3, 1, 4)  # [3, B, heads, H*W, head_dim]
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # Compute gravitational-like attention (distance-based)
        positions = torch.stack(torch.meshgrid(
            torch.arange(H, device=x.device),
            torch.arange(W, device=x.device),
            indexing='ij'
        ), dim=-1).float().reshape(H * W, 2)
        
        # Calculate distance matrix
        pos_diff = positions.unsqueeze(1) - positions.unsqueeze(0)  # [H*W, H*W, 2]
        distances = torch.norm(pos_diff, dim=-1).unsqueeze(0).unsqueeze(0)  # [1, 1, H*W, H*W]
        # Avoid division by zero
        distances = torch.clamp(distances, min=1.0)
        
        # Compute gravitational attention (inverse square law)
        grav_attention = torch.softmax(-distances, dim=-1)  # Negative for attraction
        output = torch.matmul(grav_attention, v)
        output = output.permute(0, 2, 1, 3).reshape(B, H, W, C)
        return self.out_proj(output)

class HARTLayer(nn.Module):
    """Single HART layer with morpho and cosmo attention"""
    def __init__(self, d_model: int, nhead: int = 4):
        super().__init__()
        self.morpho_attn = MorphoAttention(d_model, nhead)
        self.cosmo_attn = CosmoAttention(d_model, nhead)
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.GELU(),
            nn.Linear(d_model * 4, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # Morpho attention
        attn_out = self.morpho_attn(x)
        x = x + attn_out
        x = self.norm1(x)
        
        # Cosmo attention
        attn_out = self.cosmo_attn(x)
        x = x + attn_out
        x = self.norm1(x)
        
        # Feed forward
        ff_out = self.feed_forward(x)
        x = x + ff_out
        return self.norm2(x)

class HART(nn.Module):
    """Hybrid Autoregressive Transformer"""
    def __init__(self, d_model: int = 16, nhead: int = 4, num_layers: int = 6):
        super().__init__()
        self.layers = nn.ModuleList([
            HARTLayer(d_model, nhead) for _ in range(num_layers)
        ])
        self.output_proj = nn.Linear(d_model, 3)  # RGB output
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, d_model]
        returns: [batch, height, width, 3] (RGB)
        """
        for layer in self.layers:
            x = layer(x)
        return torch.sigmoid(self.output_proj(x))
```

"""

import torch
import numpy as np
from typing import Tuple, Dict, Any
from scipy.ndimage import convolve

class MorphogenesisEngine:
    """Biological morphogenesis simulation using reaction-diffusion"""
    
    def __init__(self, grid_size: Tuple[int, int] = (64, 64)):
        self.grid_size = grid_size
        # Default morphogen parameters (Turing pattern)
        self.diffusion_rates = {'A': 0.1, 'B': 0.05}
        self.reaction_rates = {'feed': 0.055, 'kill': 0.062}
        
    def initialize_state(self, seed: Optional[int] = None) -> Dict[str, torch.Tensor]:
        """Initialize morphogen concentrations"""
        if seed is not None:
            np.random.seed(seed)
            
        height, width = self.grid_size
        state = {
            'A': torch.zeros(1, 1, height, width) + 1.0,  # Activator
            'B': torch.zeros(1, 1, height, width) + 0.0,  # Inhibitor
        }
        # Add small random perturbations
        state['A'] += torch.randn(1, 1, height, width) * 0.1
        state['B'] += torch.randn(1, 1, height, width) * 0.1
        
        return state
    
    def reaction_diffusion_step(self, state: Dict[str, torch.Tensor]) -> Dict[str, torch.Tensor]:
        """Single step of reaction-diffusion dynamics"""
        # Laplacian kernel for diffusion
        laplacian_kernel = torch.tensor([
            [0.05, 0.2, 0.05],
            [0.2, -1.0, 0.2],
            [0.05, 0.2, 0.05]
        ], dtype=torch.float32).unsqueeze(0).unsqueeze(0)
        
        new_state = {}
        
        for morphogen, conc in state.items():
            # Diffusion
            if morphogen == 'A':
                diff_rate = self.diffusion_rates['A']
            else:
                diff_rate = self.diffusion_rates['B']
                
            laplacian = torch.nn.functional.conv2d(
                conc, laplacian_kernel, padding=1
            )
            diffusion_term = diff_rate * laplacian
            
            # Reaction terms (Gray-Scott model)
            A_conc = state['A']
            B_conc = state['B']
            
            if morphogen == 'A':
                reaction_term = (
                    -A_conc * B_conc**2 + 
                    self.reaction_rates['feed'] * (1 - A_conc)
                )
            else:  # B
                reaction_term = (
                    A_conc * B_conc**2 - 
                    (self.reaction_rates['feed'] + self.reaction_rates['kill']) * B_conc
                )
                
            new_state[morphogen] = conc + (diffusion_term + reaction_term) * 0.1
            
        return new_state
    
    def generate_pattern(self, steps: int = 100, seed: Optional[int] = None) -> torch.Tensor:
        """Generate a morphogenetic pattern"""
        state = self.initialize_state(seed)
        
        for step in range(steps):
            state = self.reaction_diffusion_step(state)
            
        # Return activator concentration as grayscale
        return state['A'].squeeze()

"""
Cosmological Structure Formation Module
"""
import torch
import numpy as np
from typing import Tuple, List
from scipy.spatial.distance import pdist, squareform

class CosmologicalStructureModule:
    """Simulates gravitational clustering of feature clusters"""
    
    def __init__(self, grid_size: Tuple[int, int] = (64, 64), G: float = 1.0):
        self.grid_size = grid_size
        self.G = G  # Gravitational constant (normalized)
        
    def initialize_clusters(self, n_clusters: int, seed: Optional[int] = None) -> Tuple[torch.Tensor, torch.Tensor]:
        """Initialize cluster positions and masses"""
        if seed is not None:
            np.random.seed(seed)
            
        height, width = self.grid_size
        positions = torch.rand(n_clusters, 2) * torch.tensor([width, height])
        masses = torch.rand(n_clusters) * 10.0 + 1.0  # Masses between 1-11
        
        return positions, masses
    
    def gravitational_force(self, positions: torch.Tensor, masses: torch.Tensor) -> torch.Tensor:
        """Compute gravitational forces between clusters"""
        n_clusters = len(positions)
        forces = torch.zeros_like(positions)
        
        for i in range(n_clusters):
            for j in range(n_clusters):
                if i != j:
                    r_vec = positions[j] - positions[i]
                    r_mag = torch.norm(r_vec)
                    if r_mag > 0.1:  # Avoid division by zero
                        force_magnitude = self.G * masses[i] * masses[j] / r_mag**2
                        force_vec = force_magnitude * r_vec / r_mag
                        forces[i] += force_vec
                        
        return forces
    
    def simulate_clustering(self, n_clusters: int = 10, steps: int = 50, seed: Optional[int] = None) -> List[torch.Tensor]:
        """Simulate gravitational clustering over time"""
        positions, masses = self.initialize_clusters(n_clusters, seed)
        velocities = torch.zeros_like(positions)
        
        trajectory = [positions.clone()]
        
        for step in range(steps):
            forces = self.gravitational_force(positions, masses)
            accelerations = forces / masses.unsqueeze(-1)
            velocities += accelerations * 0.1
            positions += velocities * 0.1
            
            # Keep positions within bounds
            positions[:, 0] = torch.clamp(positions[:, 0], 0, self.grid_size[1])
            positions[:, 1] = torch.clamp(positions[:, 1], 0, self.grid_size[0])
            
            trajectory.append(positions.clone())
            
        return trajectory

"""
Fractal Rendering Engine
"""
import torch
import numpy as np
from typing import Union, Tuple
from PIL import Image

class FractalRenderer:
    """Renders images at arbitrary resolution using fractal encoding"""
    
    def __init__(self, base_resolution: Tuple[int, int] = (16, 16)):
        self.base_resolution = base_resolution
        
    def interpolate_to_resolution(self, base_grid: torch.Tensor, target_resolution: Tuple[int, int]) -> torch.Tensor:
        """Interpolate base grid to target resolution using fractal principles"""
        # Use bilinear interpolation as base, but add fractal detail
        base_tensor = base_grid.unsqueeze(0).unsqueeze(0)  # [1, 1, H, W]
        target_tensor = torch.nn.functional.interpolate(
            base_tensor, size=target_resolution, mode='bilinear', align_corners=True
        ).squeeze(0).squeeze(0)
        
        # Add fractal detail based on zoom level
        zoom_factor = max(target_resolution) / max(self.base_resolution)
        if zoom_factor > 1:
            # Generate fractal noise at higher resolution
            noise = torch.randn(target_resolution) * (1.0 / zoom_factor)
            target_tensor = target_tensor + noise * 0.1
            
        return torch.clamp(target_tensor, 0, 1)
    
    def render_zoom_level(self, base_state: torch.Tensor, zoom_level: int) -> torch.Tensor:
        """Render at specific zoom level"""
        target_height = self.base_resolution[0] * (2 ** zoom_level)
        target_width = self.base_resolution[1] * (2 ** zoom_level)
        
        return self.interpolate_to_resolution(base_state, (target_height, target_width))
    
    def save_image(self, tensor: torch.Tensor, filename: str):
        """Save tensor as image file"""
        # Convert to PIL Image
        if tensor.dim() == 2:  # Grayscale
            tensor = tensor.unsqueeze(-1).repeat(1, 1, 3)  # Make RGB
            
        # Ensure values are in [0, 1]
        tensor = torch.clamp(tensor, 0, 1)
        
        # Convert to uint8
        img_array = (tensor.cpu().numpy() * 255).astype(np.uint8)
        img = Image.fromarray(img_array)
        img.save(filename)

"""
Hybrid Autoregressive Transformer (HART) Core Module
"""
import torch
import torch.nn as nn
import numpy as np
from typing import Tuple, Dict, Any, Optional

class MorphoAttention(nn.Module):
    """Morphogen gradient attention - measures local chemical concentration"""
    def __init__(self, d_model: int, num_heads: int = 4):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        assert self.head_dim * self.num_heads == self.d_model, "d_model must be divisible by num_heads"
        
        self.qkv_proj = nn.Linear(d_model, d_model * 3)
        self.out_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, channels]
        """
        B, H, W, C = x.shape
        qkv = self.qkv_proj(x).reshape(B, H, W, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(3, 0, 4, 1, 2, 5)  # [3, B, heads, H, W, head_dim]
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # Compute attention based on morphogen gradients
        attention_scores = torch.matmul(q, k.transpose(-2, -1)) / np.sqrt(self.head_dim)
        attention_weights = torch.softmax(attention_scores, dim=-1)
        output = torch.matmul(attention_weights, v)
        output = output.permute(0, 2, 3, 1, 4).reshape(B, H, W, C)
        return self.out_proj(output)

class CosmoAttention(nn.Module):
    """Gravitational attention - computes attraction between feature clusters"""
    def __init__(self, d_model: int, num_heads: int = 4):
        super().__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        
        assert self.head_dim * self.num_heads == self.d_model, "d_model must be divisible by num_heads"
        
        self.qkv_proj = nn.Linear(d_model, d_model * 3)
        self.out_proj = nn.Linear(d_model, d_model)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, channels]
        """
        B, H, W, C = x.shape
        # Flatten spatial dimensions for distance calculation
        flat_x = x.reshape(B, H * W, C)
        qkv = self.qkv_proj(flat_x).reshape(B, H * W, 3, self.num_heads, self.head_dim)
        qkv = qkv.permute(2, 0, 3, 1, 4)  # [3, B, heads, H*W, head_dim]
        q, k, v = qkv[0], qkv[1], qkv[2]
        
        # Compute gravitational-like attention (distance-based)
        positions = torch.stack(torch.meshgrid(
            torch.arange(H, device=x.device),
            torch.arange(W, device=x.device),
            indexing='ij'
        ), dim=-1).float().reshape(H * W, 2)
        
        # Calculate distance matrix
        pos_diff = positions.unsqueeze(1) - positions.unsqueeze(0)  # [H*W, H*W, 2]
        distances = torch.norm(pos_diff, dim=-1).unsqueeze(0).unsqueeze(0)  # [1, 1, H*W, H*W]
        # Avoid division by zero
        distances = torch.clamp(distances, min=1.0)
        
        # Compute gravitational attention (inverse square law)
        grav_attention = torch.softmax(-distances / 10.0, dim=-1)  # Normalize for stability
        output = torch.matmul(grav_attention, v)
        output = output.permute(0, 2, 1, 3).reshape(B, H, W, C)
        return self.out_proj(output)

class HARTLayer(nn.Module):
    """Single HART layer with morpho and cosmo attention"""
    def __init__(self, d_model: int, nhead: int = 4):
        super().__init__()
        self.morpho_attn = MorphoAttention(d_model, nhead)
        self.cosmo_attn = CosmoAttention(d_model, nhead)
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, d_model * 4),
            nn.GELU(),
            nn.Dropout(0.1),
            nn.Linear(d_model * 4, d_model)
        )
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(0.1)
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        # Morpho attention
        attn_out = self.morpho_attn(x)
        x = x + self.dropout(attn_out)
        x = self.norm1(x)
        
        # Cosmo attention
        attn_out = self.cosmo_attn(x)
        x = x + self.dropout(attn_out)
        x = self.norm1(x)
        
        # Feed forward
        ff_out = self.feed_forward(x)
        x = x + self.dropout(ff_out)
        return self.norm2(x)

class HART(nn.Module):
    """Hybrid Autoregressive Transformer"""
    def __init__(self, d_model: int = 16, nhead: int = 4, num_layers: int = 6):
        super().__init__()
        self.d_model = d_model
        self.layers = nn.ModuleList([
            HARTLayer(d_model, nhead) for _ in range(num_layers)
        ])
        self.output_proj = nn.Linear(d_model, 3)  # RGB output
        self.pos_encoding = nn.Parameter(torch.randn(1, 16, 16, d_model))
        
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """
        x: [batch, height, width, d_model]
        returns: [batch, height, width, 3] (RGB)
        """
        # Add positional encoding
        x = x + self.pos_encoding[:, :x.size(1), :x.size(2), :]
        
        for layer in self.layers:
            x = layer(x)
        return torch.sigmoid(self.output_proj(x))

# Example usage
if __name__ == "__main__":
    # Test the HART model
    model = HART(d_model=16, nhead=4, num_layers=2)
    input_tensor = torch.randn(1, 16, 16, 16)  # [batch, height, width, d_model]
    output = model(input_tensor)

"""
Biological Morphogenesis Engine
"""
import torch
import numpy as np
from typing import Tuple, Dict, Any, Optional
from scipy.ndimage import convolve

class MorphogenesisEngine:
    """Biological morphogenesis simulation using reaction-diffusion"""
    
    def __init__(self, grid_size: Tuple[int, int] = (64, 64), device: str = 'cpu'):
        self.grid_size = grid_size
        self.device = torch.device(device)
        # Default morphogen parameters (Turing pattern)
        self.diffusion_rates = {'A': 0.1, 'B': 0.05}
        self.reaction_rates = {'feed': 0.055, 'kill': 0.062}
        
    def initialize_state(self, seed: Optional[int] = None) -> Dict[str, torch.Tensor]:
        """Initialize morphogen concentrations"""
        if seed is not None:
            np.random.seed(seed)
            torch.manual_seed(seed)
            
        height, width = self.grid_size
        state = {
            'A': torch.ones(1, 1, height, width, device=self.device) * 1.0,  # Activator
            'B': torch.ones(1, 1, height, width, device=self.device) * 0.0,  # Inhibitor
        }
        # Add small random perturbations
        state['A'] += torch.randn(1, 1, height, width, device=self.device) * 0.1
        state['B'] += torch.randn(1, 1, height, width, device=self.device) * 0.1
        
        return state
    
    def reaction_diffusion_step(self, state: Dict[str, torch.Tensor]) -> Dict[str, torch.Tensor]:
        """Single step of reaction-diffusion dynamics"""
        # Laplacian kernel for diffusion (3x3)
        laplacian_kernel = torch.tensor([
            [0.05, 0.2, 0.05],
            [0.2, -1.0, 0.2],
            [0.05, 0.2, 0.05]
        ], dtype=torch.float32, device=self.device).unsqueeze(0).unsqueeze(0)
        
        new_state = {}
        
        for morphogen, conc in state.items():
            # Diffusion
            if morphogen == 'A':
                diff_rate = self.diffusion_rates['A']
            else:
                diff_rate = self.diffusion_rates['B']
                
            laplacian = torch.nn.functional.conv2d(
                conc, laplacian_kernel, padding=1
            )
            diffusion_term = diff_rate * laplacian
            
            # Reaction terms (Gray-Scott model)
            A_conc = state['A']
            B_conc = state['B']
            
            if morphogen == 'A':
                reaction_term = (
                    -A_conc * B_conc**2 + 
                    self.reaction_rates['feed'] * (1 - A_conc)
                )
            else:  # B
                reaction_term = (
                    A_conc * B_conc**2 - 
                    (self.reaction_rates['feed'] + self.reaction_rates['kill']) * B_conc
                )
                
            new_state[morphogen] = conc + (diffusion_term + reaction_term) * 0.1
            
        return new_state
    
    def generate_pattern(self, steps: int = 100, seed: Optional[int] = None) -> torch.Tensor:
        """Generate a morphogenetic pattern"""
        state = self.initialize_state(seed)
        
        for step in range(steps):
            state = self.reaction_diffusion_step(state)
            
        # Return activator concentration as grayscale
        return state['A'].squeeze().cpu()

# Example usage

"""
Cosmological Structure Formation Module
"""
import torch
import numpy as np
from typing import Tuple, List, Optional
from scipy.spatial.distance import pdist, squareform

class CosmologicalStructureModule:
    """Simulates gravitational clustering of feature clusters"""
    
    def __init__(self, grid_size: Tuple[int, int] = (64, 64), G: float = 1.0, device: str = 'cpu'):
        self.grid_size = grid_size
        self.G = G  # Gravitational constant (normalized)
        self.device = torch.device(device)
        
    def initialize_clusters(self, n_clusters: int, seed: Optional[int] = None) -> Tuple[torch.Tensor, torch.Tensor]:
        """Initialize cluster positions and masses"""
        if seed is not None:
            np.random.seed(seed)
            torch.manual_seed(seed)
            
        height, width = self.grid_size
        positions = torch.rand(n_clusters, 2, device=self.device) * torch.tensor([width, height], device=self.device)
        masses = torch.rand(n_clusters, device=self.device) * 10.0 + 1.0  # Masses between 1-11
        
        return positions, masses
    
    def gravitational_force(self, positions: torch.Tensor, masses: torch.Tensor) -> torch.Tensor:
        """Compute gravitational forces between clusters"""
        n_clusters = len(positions)
        forces = torch.zeros_like(positions)
        
        for i in range(n_clusters):
            for j in range(n_clusters):
                if i != j:
                    r_vec = positions[j] - positions[i]
                    r_mag = torch.norm(r_vec)
                    if r_mag > 0.1:  # Avoid division by zero
                        force_magnitude = self.G * masses[i] * masses[j] / r_mag**2
                        force_vec = force_magnitude * r_vec / r_mag
                        forces[i] += force_vec
                        
        return forces
    
    def simulate_clustering(self, n_clusters: int = 10, steps: int = 50, dt: float = 0.1, seed: Optional[int] = None) -> List[torch.Tensor]:
        """Simulate gravitational clustering over time"""
        positions, masses = self.initialize_clusters(n_clusters, seed)
        velocities = torch.zeros_like(positions)
        
        trajectory = [positions.clone()]
        
        for step in range(steps):
            forces = self.gravitational_force(positions, masses)
            accelerations = forces / masses.unsqueeze(-1)
            velocities += accelerations * dt
            positions += velocities * dt
            
            # Keep positions within bounds
            positions[:, 0] = torch.clamp(positions[:, 0], 0, self.grid_size[1])
            positions[:, 1] = torch.clamp(positions[:, 1], 0, self.grid_size[0])
            
            trajectory.append(positions.clone())
            
        return trajectory

# Example usage
if __name__ == "__main__":

"""
Fractal Rendering Engine
"""
import torch
import numpy as np
from typing import Union, Tuple, Optional
from PIL import Image

class FractalRenderer:
    """Renders images at arbitrary resolution using fractal encoding"""
    
    def __init__(self, base_resolution: Tuple[int, int] = (16, 16), device: str = 'cpu'):
        self.base_resolution = base_resolution
        self.device = torch.device(device)
        
    def interpolate_to_resolution(self, base_grid: torch.Tensor, target_resolution: Tuple[int, int]) -> torch.Tensor:
        """Interpolate base grid to target resolution using fractal principles"""
        # Use bilinear interpolation as base, but add fractal detail
        base_tensor = base_grid.unsqueeze(0).unsqueeze(0)  # [1, 1, H, W]
        target_tensor = torch.nn.functional.interpolate(
            base_tensor, size=target_resolution, mode='bilinear', align_corners=True
        ).squeeze(0).squeeze(0)
        
        # Add fractal detail based on zoom level
        zoom_factor = max(target_resolution) / max(self.base_resolution)
        if zoom_factor > 1:
            # Generate fractal noise at higher resolution
            noise = torch.randn(target_resolution, device=self.device) * (1.0 / zoom_factor)
            target_tensor = target_tensor + noise * 0.1
            
        return torch.clamp(target_tensor, 0, 1)
    
    def render_zoom_level(self, base_state: torch.Tensor, zoom_level: int) -> torch.Tensor:
        """Render at specific zoom level"""
        target_height = self.base_resolution[0] * (2 ** zoom_level)
        target_width = self.base_resolution[1] * (2 ** zoom_level)
        
        return self.interpolate_to_resolution(base_state, (target_height, target_width))
    
    def save_image(self, tensor: torch.Tensor, filename: str):
        """Save tensor as image file"""
        # Convert to PIL Image
        if tensor.dim() == 2:  # Grayscale
            tensor = tensor.unsqueeze(-1).repeat(1, 1, 3)  # Make RGB
            
        # Ensure values are in [0, 1]
        tensor = torch.clamp(tensor, 0, 1)
        
        # Convert to uint8
        img_array = (tensor.cpu().numpy() * 255).astype(np.uint8)
        img = Image.fromarray(img_array)
        img.save(filename)
        
    def tensor_to_pil(self, tensor: torch.Tensor) -> Image.Image:
        """Convert tensor to PIL Image without saving"""
        if tensor.dim() == 2:  # Grayscale
            tensor = tensor.unsqueeze(-1).repeat(1, 1, 3)  # Make RGB
            
        # Ensure values are in [0, 1]
        tensor = torch.clamp(tensor, 0, 1)
        
        # Convert to uint8
        img_array = (tensor.cpu().numpy() * 255).astype(np.uint8)
        return Image.fromarray(img_array)

# Architecture Overview

## Core Principles

HART-Morphosis is built on four foundational pillars:

### 1. Hybrid Autoregressive Transformers (HART)
The HART core combines two specialized attention mechanisms:
- **Morpho-Attention**: Measures local morphogen concentration gradients inspired by biological development
- **Cosmo-Attention**: Computes gravitational attraction between feature clusters based on cosmological structure formation

### 2. Biological Morphogenesis Engine
Implements reaction-diffusion systems (Turing patterns) to generate organic structures:
- Activator-inhibitor dynamics create spots, stripes, and branching patterns
- L-system grammar generates hierarchical structures (trees, veins, lightning)
- Local rule application enables parallel processing and edge deployment

### 3. Cosmological Structure Module
Simulates gravitational clustering to organize global composition:
- Feature clusters are assigned "mass" based on semantic importance
- Inverse-square law governs attraction/repulsion between features
- Hierarchical clustering creates natural composition (faces centered, landscapes balanced)

### 4. Fractal Rendering Engine
Enables infinite resolution through recursive rule application:
- Base state (16×16) stored as seed + rules
- Higher resolutions generated by applying rules recursively
- True zoom without artifacts — only increasing detail

## Data Flow

```
[Text Prompt] 
    ↓
[HART Core: Processes prompt into latent seed]
    ↓
[Morphogenesis Engine: Grows organic patterns]
    ↓
[Cosmological Module: Organizes global structure]
    ↓
[Fractal Renderer: Generates output at requested resolution]
    ↓
[Final Image]
```

# API Reference

## Core Modules

### `hart_morphosis.HART`
Hybrid Autoregressive Transformer for image refinement.

```python
from hart_morphosis import HART

model = HART(d_model=16, nhead=4, num_layers=6)
output = model(input_tensor)  # [batch, height, width, 3]
```

**Parameters:**
- `d_model` (int): Dimension of model features (default: 16)
- `nhead` (int): Number of attention heads (default: 4)
- `num_layers` (int): Number of HART layers (default: 6)

**Methods:**
- `forward(x)`: Process input tensor through HART layers

### `hart_morphosis.MorphogenesisEngine`
Biological morphogenesis simulation using reaction-diffusion.

```python
from hart_morphosis import MorphogenesisEngine

engine = MorphogenesisEngine(grid_size=(16, 16))
pattern = engine.generate_pattern(steps=50, seed=42)
```

**Parameters:**
- `grid_size` (tuple): Initial grid dimensions (default: (64, 64))
- `device` (str): Device for computation (default: 'cpu')

**Methods:**
- `generate_pattern(steps, seed)`: Generate morphogenetic pattern
- `initialize_state(seed)`: Initialize morphogen concentrations
- `reaction_diffusion_step(state)`: Single reaction-diffusion step

### `hart_morphosis.CosmologicalStructureModule`
Cosmological structure formation simulation.

```python
from hart_morphosis import CosmologicalStructureModule

module = CosmologicalStructureModule(grid_size=(16, 16))
trajectory = module.simulate_clustering(n_clusters=8, steps=20, seed=42)
```

**Parameters:**
- `grid_size` (tuple): Simulation space dimensions (default: (64, 64))
- `G` (float): Gravitational constant (default: 1.0)
- `device` (str): Device for computation (default: 'cpu')

**Methods:**
- `simulate_clustering(n_clusters, steps, seed)`: Simulate gravitational clustering
- `initialize_clusters(n_clusters, seed)`: Initialize cluster positions and masses
- `gravitational_force(positions, masses)`: Compute gravitational forces

### `hart_morphosis.FractalRenderer`
Fractal rendering engine for infinite resolution.

```python
from hart_morphosis import FractalRenderer

renderer = FractalRenderer(base_resolution=(16, 16))
zoomed_image = renderer.render_zoom_level(base_state, zoom_level=4)
```

**Parameters:**
- `base_resolution` (tuple): Base grid dimensions (default: (16, 16))
- `device` (str): Device for computation (default: 'cpu')

**Methods:**
- `render_zoom_level(base_state, zoom_level)`: Render at specific zoom level
- `save_image(tensor, filename)`: Save tensor as image file
- `tensor_to_pil(tensor)`: Convert tensor to PIL Image

## Command Line Interface

```bash
python -m src.hart_morphosis.cli.main --prompt "face in galaxy" --zoom 4 --seed 42 --output result.png
```

**Arguments:**
- `--prompt`: Text prompt for generation (required)
- `--output`: Output filename (default: output.png)
- `--zoom`: Zoom level (power of 2, default: 4)
- `--seed`: Random seed (default: 42)

# Usage Examples

## Basic Generation

```python
from hart_morphosis import HART, MorphogenesisEngine, CosmologicalStructureModule, FractalRenderer

# Initialize components
hart = HART(d_model=16, num_layers=4)
morpho_engine = MorphogenesisEngine(grid_size=(16, 16))
cosmo_module = CosmologicalStructureModule(grid_size=(16, 16))
renderer = FractalRenderer(base_resolution=(16, 16))

# Generate base pattern
morpho_pattern = morpho_engine.generate_pattern(steps=50, seed=42)

# Create initial state
base_state = morpho_pattern.unsqueeze(0).unsqueeze(-1).repeat(1, 1, 16)
base_state = base_state.unsqueeze(0)

# Refine with HART
refined_image = hart(base_state).squeeze(0)

# Render at high resolution
high_res_image = renderer.render_zoom_level(refined_image.squeeze(), zoom_level=6)
renderer.save_image(high_res_image, "high_res_output.png")
```

## Batch Processing

```python
import torch
from hart_morphosis import HART, MorphogenesisEngine, FractalRenderer

# Initialize once
hart = HART(d_model=16, num_layers=4)
morpho_engine = MorphogenesisEngine(grid_size=(16, 16))
renderer = FractalRenderer(base_resolution=(16, 16))

# Generate multiple images
prompts = ["cosmic forest", "neural galaxy", "biological circuit"]
for i, prompt in enumerate(prompts):
    morpho_pattern = morpho_engine.generate_pattern(steps=50, seed=i)
    base_state = morpho_pattern.unsqueeze(0).unsqueeze(-1).repeat(1, 1, 16).unsqueeze(0)
    refined_image = hart(base_state).squeeze(0)
    renderer.save_image(refined_image.squeeze(), f"{prompt.replace(' ', '_')}.png")
```

      with:
        file: ./coverage.xml
        flags: unittests
        name: codecov-umbrella
        fail_ci_if_error: false

  deploy-hf:
    needs: test
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.10'

    - name: Deploy to Hugging Face Spaces
      env:
        HF_TOKEN: ${{ secrets.HF_TOKEN }}

      run: |
        # Create space if it doesn't exist

        # Copy files to temporary directory
        mkdir -p /tmp/hf-space
        cp -r web_ui/* /tmp/hf-space/
        cp -r src /tmp/hf-space/

        cp README.md /tmp/hf-space/
        cp LICENSE /tmp/hf-space/
        
        # Create app.py symlink if needed
        ln -sf /tmp/hf-space/app.py /tmp/hf-space/app.py
        
        # Push to Hugging Face
        cd /tmp/hf-space
        git init
        git add .
        git config --global user.email "actions@github.com"
        git config --global user.name "GitHub Actions"
        git commit -m "Deploy from GitHub Actions"
        git remote add origin https://$HF_TOKEN@huggingface.co/spaces/$HF_REPO_ID
