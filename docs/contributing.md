# Contributing

HART-Morphosis is **defensively published** under CC0 1.0.  
**No patents. No ownership. No restrictions.**

## How to Contribute

1. **Fork** the repo
2. Add a new rule set in `src/hart_morphosis/models/rulesets/`
3. Improve the web UI
4. Add a notebook
5. Port to TinyML (ESP32, Arduino)
6. Write a blog post or paper

## Submitting Changes

- Open a **Pull Request**
- Include:
  - Description of change
  - Screenshots (if visual)
  - Benchmark (if performance-related)
- No CLA required. No license changes.

## Code Style

- Use `black`, `isort`, `flake8`
- Write docstrings
- Keep code functional, not complex

## Want to Build a Product?

Go ahead.  
You don’t need permission.  
You don’t owe us anything.  
Just share your work.
