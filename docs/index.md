## 🧩 Core Concepts

- **HART**: Hybrid Autoregressive Transformer — attention based on morphogen gradients and gravitational clustering.
- **Morphogenesis**: Reaction-diffusion systems (Turing patterns) that grow textures, veins, trees.
- **Cosmological Structure**: Gravitational N-body simulation that organizes features into galaxies, filaments, voids.
- **Fractal Encoding**: Store only rules + seed. Render any resolution on-demand. No upscaling. No blur.
